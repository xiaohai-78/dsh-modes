# 保存的提示词对正在运行的会话生效

改过提示词的模式会换用一个「即时生效」的身份行：每次拼装系统提示词时，它读取这个模式最新保存的提示词。这样保存后的提示词从下一步起就作用于这个模式里正在运行的会话，而不只是新会话。DSH 会把这次变化记进会话日志。在能接受后续系统消息的路线上，DSH 把新提示词追加在已缓存的历史之后，缓存的前缀仍能命中；在其他路线上，它改写第一条系统消息，这个会话的提示词缓存会失效。只有提示词开头和结尾的文字是这样生效的；「完整提示词」和「运行时上下文」两个开关仍然只对新会话生效。

## 考虑过的做法

- **只对新会话生效**（DSH 的默认行为）：用户在正测试的那个对话里改了提示词，会觉得没有任何效果。
