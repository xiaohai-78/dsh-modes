# 页面是单个文件，不需要构建

页面就是一个 `client.js`，由 DSH 的模块加载器原样运行：React 用 `React.createElement`，不用 JSX，不打包，中英文文字放在文件里的两个词典中。这样插件运行的就是发布出去的那份文件，不会有忘了提交或和源码对不上的构建产物；测试也能直接读这个文件，检查页面用到的每个词条在两种语言里都有。dsh-modes、dsh-mode-skills 和 dsh-request-params 三个插件保持这个结构一致。

## 考虑过的做法

- **JSX 加打包工具**：页面代码更短，但每次发布都要依赖构建这一步，还得保证构建产物和源码一致。
